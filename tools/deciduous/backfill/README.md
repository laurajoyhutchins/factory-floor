# Deciduous backfills

Historical graph backfills live here as evidence ledgers paired with reviewable JSON snapshots under `.deciduous/exports/`.

Backfills must follow the repository's Deciduous authority boundaries: repository records remain authoritative, unsupported explanations are omitted, and the graph captures consequential model changes rather than every commit.
